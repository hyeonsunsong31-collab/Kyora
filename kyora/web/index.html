Honesty

Kyora is an orchestration application. It calls four external systems over their own APIs, each in a fixed role: NVIDIA Nemotron-3-Ultra writes design prose, UI spec and narration; Kimi K3 plans, judges the code engine's file writes and shell commands that Kyora's local rules do not settle (reads are not judged; rules allow standard game paths and read-only commands) and reviews; Claude Code implements and tests at the effort set in Settings (now --effort -) through your Claude subscription; NVIDIA Tokkio presents.

Kyora is not a merged model, a fine-tune or a lighter copy of any of them. Nothing here is generated locally and nothing is simulated: a missing engine shows as BLOCKED, a missing metric shows as -.

  • The pass rate is a gate, not a score. Each run must pass at least the share of its counted checks (static, Node and in-browser acceptance tests) set in Settings (now -; each run records the threshold it used) and all required checks, or it loops through Kimi review and engine fixes a bounded number of times. Kyora Bench applies the same rule to fixed tasks at each task's own threshold (never below 94 %) and only grants a badge when your measured run clears it.
  • TOPS is not displayed. Compute lives in NVIDIA's and Anthropic's datacenters; it cannot be measured or set over an API. Kyora shows what it can measure: tokens per second, time to first token, latency, token counts and reachability.
  • Model names are shown as resolved. If Claude Code falls back to another model, the active model is displayed, not the requested one.
